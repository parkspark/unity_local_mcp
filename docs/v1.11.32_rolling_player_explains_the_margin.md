# v1.11.32 — 여유의 정체는 구르는 플레이어였다

v1.11.31이 경계를 찾고도 승격을 보류한 이유는 **"여유가 왜 필요한지 설명하지
못했다"**였다. 그 질문의 답이 실행 로그 안에 있었다.

---

## 1. 추적

v1.11.31의 스윕에서 간격 −0.199인데 획득이 안 됐다. 기하로는 닿아야 했다. 플레이어의
런타임 자세를 봤다.

```text
pos=0.00, 1.50, 0   euler Z=0.000002    extents=(0.500, 1.000, 0.5)
pos=4.95, 1.499, 0  euler Z=173.27      extents=(0.559, 0.997, 0.5)   ← d 구간 끝
pos=-5.05, 1.492, 0 euler Z=191.49      extents=(0.600, 0.990, 0.5)   ← a 구간 끝
```

**캡슐이 Z축으로 구른다.** `Rigidbody.constraints = 0` — 회전이 하나도 잠겨 있지 않다.
캡슐이 누우면 세로 반폭이 **1.0에서 0.5로 줄어든다.**

호스트는 구간 **양 끝에서만** 형상을 잰다. 그 두 지점의 각도는 173°·191°로 거의
수직이라 `extents.y ≈ 1.0`이 찍히지만, x=3을 지날 때는 그 사이 어딘가 90° 근처였다.
그때 머리 끝은 2.5가 아니라 **2.0**이고, 아이템 바닥 2.3에 닿지 않는다.

그리고 이것이 `y=2.5`(아이템 바닥 2.0)에서 정확히 뒤집힌 이유다 — **누운 캡슐의 머리
높이가 딱 2.0**이다.

## 2. 검증 — A/B

같은 씬, 같은 아이템 위치, **바뀐 것은 회전 잠금 하나**다.

| | 간격 | `disappeared` | 플레이어 euler Z |
|---|---|---|---|
| `constraints = 0` (회전 자유) | −0.199 | **False** | 0 → 173.27 |
| `constraints = 112` (회전 잠금) | −0.198 | **True** | 내내 0 |

**여유는 간격 공식의 근사 오차가 아니었다.** 측정 중 플레이어의 형상이 변하는데
양 끝에서만 재고 있던 것이고, 형상이 변한 이유는 씬 쪽 결함이다.

즉 **경계는 원래 0 근처**이고, v1.11.31이 본 "−0.35 ~ −0.50"은 구르는 플레이어가
만든 허수였다.

## 3. 얼마나 흔한가

기록된 실행 전체에서 플레이어의 최대 기울기를 셌다. 180도 뒤집힌 캡슐은 AABB가
똑바로 선 것과 같으므로 **가장 가까운 180도 배수에서 벗어난 각도**로 잰다.

```text
플레이어 기울기를 관측한 실행: 150
  0~5도    49회  (33%)
  5~15도   39회  (26%)
  15~45도  14회  ( 9%)
  45~90도  48회  (32%)
```

**3분의 1이 완전히 넘어간다.** 이 실행들의 `surface_gap`은 액면 그대로 읽으면 안 된다.

> 이 사이클 도중 한 번 **101/150(67%)이 15도 넘게 기운다**고 보고했는데, 그것은
> 360도 기준으로 재서 173°를 "173도 기울었다"로 계산한 값이었다. 위가 맞는 수치다.

## 4. 변경 내용

간격 옆에 **그 간격을 믿어도 되는지**를 함께 남긴다. 판정은 하지 않는다.

```json
{"contact_candidates": [...], "player_max_tilt": 90.0}
```

`player_max_tilt`가 크면 위의 `surface_gap`은 겹침을 과장한 값이다. 임계값을 고를 때
이 축으로 표본을 갈라야 한다.

**판정을 붙이지 않은 이유.** 구르는 플레이어를 실패로 만들 근거가 아직 없다 — 32%가
넘어가지만 그 때문에 실패한 실행은 확인되지 않았다. `require_player_constraints`가
이미 있으나 2.5D 요청에만 걸린다. 범위를 넓히려면 E4가 `RequireComponent`를 기각할
때 쓴 것과 같은 계수가 필요하다.

## 5. 검증

### 5.1 실측

§2의 A/B와 §3의 재생 150건.

### 5.2 단위 테스트

**298 → 299건**, subtest 48건. 전부 통과. 새 1건은 기울기가 최대치로 누적되는 것과
180도 뒤집힘을 수직으로 보는 것을 고정한다.

### 5.3 측정하지 않은 것

- **회전 잠금 상태의 경계 표본이 1건뿐이다**(−0.198 → True). 0 근처의 경계를 주장하려면
  양쪽으로 더 필요하다. A0 승격은 여전히 보류다
- **구르는 것이 실패를 만드는지 확인하지 않았다** (§4)
- 접촉 후보의 좌표는 여전히 시작 시점 한 번만 찍는다
