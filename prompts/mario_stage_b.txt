CLI의 `--project`로 지정된 격리 프로젝트에서, **이미 있는 씬** `Assets/Scenes/Mario1A.unity`를 열어 마리오 1-1의 레벨 지오메트리를 추가해줘. 조작은 이미 완성돼 있다.

[격리 및 오염 방지 — 최우선]
- 이 요청의 유일한 작업 씬은 `Assets/Scenes/Mario1A.unity`다. **새 씬을 만들지 마라.** 그 씬을 열어 확장하고 같은 경로에 저장하라.
- `Assets/Scenes`의 다른 모든 씬은 열거나 변경·저장·삭제하지 마라. **어떤 파일도 삭제하지 마라.**
- 기존 `Player`와 `Main Camera`, 그리고 그 컴포넌트 설정을 **변경하지 마라.** 이미 검증을 통과한 구성이다.
- 스크립트는 이 단계에서 **만들지도 고치지도 마라.** 씬 오브젝트만 추가·수정한다.
- 검증 실패 시 씬을 재생성하지 말고 실패한 항목만 수정한 뒤 재검증하라.

[중요]
이 요청은 제작, Play Mode 실측 검증, 실패 수정, 재검증까지 포함한다.
모델의 설명만으로 완료하지 말고 모든 합격 조건을 실제 Unity 도구 결과로 확인해라.
최종 완료 판정은 호스트 검증에 맡겨라.

[레벨 지오메트리 — 1-1의 뼈대]
오브젝트는 3개 이상이므로 `unity_create_gameobjects` 배치 툴을 한 번에 사용해 만든다. 전부 Cube 프리미티브다.

- 기존 `Ground`의 크기와 위치를 바꿔 첫 구간으로 만든다
  - Ground: 위치 (13.5, -0.5, 0), 크기 (33, 1, 4)   → x −3 ~ 30
- 지면 두 구간을 추가하고 그 사이를 낙사 구덩이로 남긴다
  - Ground2: 위치 (47, -0.5, 0), 크기 (26, 1, 4)    → x 34 ~ 60
  - Ground3: 위치 (78, -0.5, 0), 크기 (28, 1, 4)    → x 64 ~ 92
- 파이프 3개 (내려가는 동작은 구현하지 않는다)
  - Pipe1: 위치 (22, 0.5, 0), 크기 (2, 2, 2)
  - Pipe2: 위치 (40, 1.0, 0), 크기 (2, 3, 2)
  - Pipe3: 위치 (52, 1.5, 0), 크기 (2, 4, 2)
- 공중 블록 — 밑면이 y 3.5 이상이어야 플레이어가 밑을 지나갈 수 있다
  - BrickRow1: 위치 (14, 4, 0), 크기 (6, 1, 2)
  - QuestionBlock1: 위치 (18, 4, 0), 크기 (1, 1, 2)
  - BrickRow2: 위치 (34, 5, 0), 크기 (4, 1, 2)
- 종반 계단 4단
  - Step1: 위치 (68, 0.5, 0), 크기 (2, 1, 4)
  - Step2: 위치 (70, 1.0, 0), 크기 (2, 2, 4)
  - Step3: 위치 (72, 1.5, 0), 크기 (2, 3, 4)
  - Step4: 위치 (74, 2.0, 0), 크기 (2, 4, 4)
- 목표 지점
  - Flagpole: 위치 (86, 3, 0), 크기 (0.4, 7, 0.4)

[검증 통로 — 반드시 지켜라]
- 플레이어 시작 위치는 (0, 1, 0)이고 바뀌면 안 된다
- **x −8 부터 8 사이에는 어떤 오브젝트도 두지 마라.** 위 좌표는 이미 그 조건을 지킨다. 임의로 옮기지 마라
- 공중 블록의 밑면은 플레이어 머리보다 확실히 높아야 한다
- 모든 오브젝트에 Collider가 있어야 한다

[Play Mode 합격 조건]
1. 컴파일 오류와 예외가 0건
2. 씬이 Assets/Scenes/Mario1A.unity 로 저장되고 isDirty=false
3. Play Mode 진입 후 런타임 오류가 0건
4. 무입력 0.5초 동안 Player X 변화가 0.05 이하
5. D를 1초 누르면 Player X가 2 이상 증가
6. A를 1초 누르면 Player X가 2 이상 감소
7. Right Arrow 입력으로도 Player X가 증가
8. Space 입력 후 Player Y가 0.5 이상 상승
9. 점프 후 다시 바닥에 착지
10. D만 0.5초 입력한 이동 거리와 D+LeftShift를 입력한 거리를 측정하고, 대시 이동 거리가 더 길 것
11. A+LeftShift에서도 왼쪽 방향으로 같은 대시 효과 확인
12. Player 이동 중 Main Camera X가 같은 방향으로 이동
13. Play 중 Game View 스크린샷 저장
14. 모든 가상 키의 held와 pendingReleases가 비어 있음
15. 검증 종료 후 Play Mode가 반드시 종료됨

[검증 순서]
- 씬과 컴포넌트 확인
- 컴파일 오류 확인
- Play Mode 진입
- 무입력 기준 좌표 측정
- D 이동 측정
- A 이동 측정
- Space 점프의 여러 시점 Y 좌표 측정
- 일반 이동과 Shift 대시 이동 거리를 동일한 시간으로 비교
- 카메라 좌표 변화 측정
- 런타임 오류 확인
- 스크린샷 생성
- 모든 키 해제
- Play Mode 종료
- 최종 상태 확인

합격 조건 중 하나라도 측정되지 않았거나 실패하면 완료라고 보고하지 말고 수정 후 해당 검증을 반복해라.
